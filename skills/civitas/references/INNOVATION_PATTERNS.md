# Future invention from institutional and systems mechanisms

Create technologies and institutions that solve human problems instead of merely adding an AI interface.

## Ten lenses for invention

1. **Missing coordination:** Actors want the same outcome but cannot trust commitments; create verification, reversible coordination or shared standards.
2. **Broken externality:** One actor gains while others bear hidden costs; create measurement, accountability or safer alternatives.
3. **Information asymmetry:** One party cannot assess claims; create provenance, audits and interpretable records.
4. **Institutional gap:** Technology scales faster than the rules that govern it; create consent, dispute and accountability structures.
5. **Maintenance deficit:** Valuable systems fail through neglect; create repair incentives and lifecycle planning.
6. **Knowledge bottleneck:** Expertise cannot reach where needed; create authorized transfer, education, or collective memory.
7. **Network lock in:** A dominant intermediary owns participation; create interoperable exit and portable reputation.
8. **Fragile abundance:** Cheap resources trigger dependency; create resilience, rationing or diversified supply.
9. **Long horizon mismatch:** Actors receive short term rewards for long term damage; create measurable stewardship without coercion.
10. **Agent responsibility gap:** Machines perform tasks but accountability is unclear; create permissioned workflows and human review.

## Novelty filter

For each idea specify the status quo, distinct structural mechanism, why recent capabilities matter, user with a real problem, implementation path, testable unit economics when relevant, expected adoption barrier, strongest existing alternative, unsafe failure case, and evidence gaps. Avoid claiming a monopoly on an idea without a current competitor search.

## Mini experiment

Use one reversible pilot. Define a falsifiable claim, a baseline, minimal feature set, recruiting plan, primary value metric, guardrail metric, stop criterion and follow on decision. Avoid data collection that people have not agreed to.

## Originality constraint

Literary inspiration can guide thinking, but do not reproduce characters, specific plot sequences, organizations or distinctive expressions from any source. Attribute broad inspiration honestly. A new product should remain useful to someone who has never read Asimov.
